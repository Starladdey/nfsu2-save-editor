Need for Speed Underground 2 Save File Location (Windows 10 & 11)

Updated November 7, 2026 · by Starladdey

On Windows 10 and Windows 11, your Need for Speed Underground 2 career saves live in a hidden AppData folder. Here is the fastest way to open it, what you will find inside, and how to back up and edit your save safely.

The NFSU2 save folder path

NFS Underground 2 stores career save files in %LOCALAPPDATA%\NFS Underground 2, which expands to C:\Users\<YourUsername>\AppData\Local\NFS Underground 2.

  1. Press Win + R to open the Run dialog.
  2. Paste %LOCALAPPDATA%\NFS Underground 2 and press Enter.
  3. Windows Explorer opens the folder. Open the subfolder named after your career profile.
Tip: the Run dialog expands %LOCALAPPDATA% for you, so you do not need to unhide the AppData folder. In the editor, the Copy Path button in the top bar copies this path to your clipboard.

What is inside your profile folder

Every career profile gets its own folder, named after the profile. The save file inside has the same name as the profile, and that is the file you load into the editor.

Profile names are limited to 7 ASCII characters. If you rename a profile in the editor, place the downloaded file inside a folder with the new name; the editor reminds you which folder to use.

Back up your save before editing

  • Close the game completely before touching any save file.
  • Copy the whole profile folder somewhere safe, for example to your Desktop.
  • Or tick Auto .bak in the editor's top bar: it downloads an untouched .bak copy every time you save.

Edit the save file in your browser

  1. Open the NFSU2 Save Editor and drop your save file (or a .zip archive, or GARAGE.DAT) onto the load area.
  2. Change money, garage cars, unlocks or Outrun Uniques.
  3. Click Download Save and replace the original file in your profile folder.

The editor recalculates all three CRC-32 checksums in the file header automatically, so the game does not show a damaged or corrupted save warning. Your save is parsed and edited locally in your browser and is never uploaded to a server.

Saves from nfsu2.xyz (web port)

Export: download your save archive (.zip) from nfsu2.xyz, open NFS Underground 2 → your profile folder, and drop the file that matches your profile name into the editor. For slots 6–10, load GARAGE.DAT instead (see the GARAGE.DAT guide).

Import back: click Restore on nfsu2.xyz, select your edited save file (or GARAGE.DAT) and confirm the replacement.

Frequently asked questions

I can't see the AppData folder. What should I do?

Use the Win + R method: pasting %LOCALAPPDATA%\NFS Underground 2 into the Run dialog opens the folder directly, even if hidden items are turned off in Explorer.

Does the editor upload my save file?

No. Save files are parsed and edited 100% locally in your browser memory and are never sent to any server.

The game says my save is damaged after editing. Why?

That happens when a save is changed without fixing its checksums. Files downloaded from this editor have all three CRC-32 checksums recalculated automatically. If something still looks wrong, restore your backup copy.
